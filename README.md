One line of the worst advice an AI assistant could give, in a confident and tidy AI voice: quit your hospital job first, then figure out the online business, funded by the cash hidden in your bedroom. What could go wrong? The repository holds a small Node program, `main.ts`, that writes that single line (136 characters) to `/output/entry.txt`, byte for byte the same on every run, well inside the 140-character gate.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
